# Agent 工具说明维护

原生 VCP 入口使用 `TVStxt/supertool.txt`；MCP / ChatGPT 入口使用 `TVStxt/McpToolCall.txt` 并遵守当前 MCP schema。两份说明不能混用。

原生指南引用现有 `VCPDynamicTools` 占位符，提供当前可用工具摘要；具体参数取自匹配身份的插件 manifest。动态目录关闭、不可用或输出被截断时，缺失工具不能凭旧手册推定为可用。请求展开详细说明可使用现有 `[[VCPDynamicTools:tool=精确名称]]` 指令；这只是请求目录展开，不执行工具，也不授予权限。

文件、媒体、记忆、通讯等静态工具箱是参考手册，可能包含尚未连接的客户端能力。客户端与服务器工具名称、执行机器及路径不可混淆。注册在线也不证明宿主依赖或外部供应商正常。

维护插件说明时，应检查 `capabilities.invocationCommands` 中的 `description` 和 `example`；自调用示例的 tool_name 必须与 manifest 的 name 一致。服务器插件不得继续使用客户端同类工具的名称作为示例。执行器不保证存在别名。

maid、folder、索引选择器描述检索或写入范围，不能替代访问授权。说明不得建议通过换署名访问其他所有者的记忆。保留具体工具的审批、数据保护和失败处理要求。

默认 Agent 模板不得把图床访问键拼进模型提示词或输出；仅使用工具返回且获准向当前用户展示的完整图片地址。Hornet 默认模板已去除访问键占位符；这不改变图床服务端鉴权，也不证明其他本地模板或已存在的会话已清理。

本仓库中的 TVStxt 和 Agent 是默认内容。生产部署可能把它们绑定到外部状态目录；更新源码不等于生产说明已更新。应用修订前必须逐文件比较实际版本，保留本地补充、原文件与校验值，并按实际授权执行。不要用源码默认文件整目录覆盖已有 Agent 或工具手册。

验证应覆盖说明中的精确工具名、参数编码、动态目录对离线工具的筛选、占位符展开和模拟访问键不会进入已修订模板。离线检查使用模拟配置和替代管理器，不读取私有配置、不把真实提示词发送给模型；它不能证明真实工具在线执行成功。
