# DailyNote 更新范围（R1-C）

update必须给出有效maid或folder，禁止缺失后查全库。maid只是作者文本；folder是定位范围，不是可信身份或资源修改授权。

- 作者范围：作者同名目录、作者名加“的…”目录；不把nova误认为novax。
- 公共范围：公共、公共的…、公共_…；它不授予任何主体公共资源写权限。
- 其他显式分类：仅该精确目录，或唯一规范化别名，不向相似目录回退。
- fileName只对既定范围做大小写不敏感片段筛选，不允许路径/通配符。target在筛选后的扫描范围须唯一命中，零或多处不写。
- 作者/目录的路径状和不可见控制字符输入拒绝。有效target规范化后也须至少15个UTF-16文本单元；过短时提供更长的已知旧文本。
- 宽松匹配替换原文实际区间，保留两侧文本，不以target长度截断原文。

读取与提交验证稳定文件身份/版本、拒绝symlink/hardlink和未完整扫描时写入。无稳定inode或链接计数不满足时fail-closed。当前Linux合成回归通过；Windows实际文件系统验收未运行。

协作并发由既有resident FIFO与KBD协调；并不提供与任意非协作本地进程之间的全目录事务或原子CAS。身份/Topic授权与OS强隔离未在本插件实现；部署时必须维持外层既有授权边界，不能将目录过滤解释为完整ACL。详review/upstream-r1c的源码审查与HANDOFF。
